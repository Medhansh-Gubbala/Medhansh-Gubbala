# Hi, I'm Medhansh

I build software products end to end: I write the spec, design the architecture, and direct teams of AI coding agents to build it, then verify every piece against the running system. Most of my work is full-stack TypeScript (Next.js, React, SQLite/Postgres), agent orchestration with Claude Code, and Roblox game development in Luau.

## Private and commercial work

These repositories are private because they are, or will become, products. Happy to walk through any of them.

- **Rodev**: my own AI game-development studio for Roblox. A Node daemon plus React control room that plans features into task boards, runs several agents in parallel git worktrees, playtests inside Roblox Studio through MCP, and gates every merge on typechecks, lint and a cross-model code review. 148 commits, 4 games in progress.
- **toolkit-app**: a multi-tenant SaaS that builds and deploys websites for customers (Clerk organizations, Supabase row-level security, sandboxed agent code generation, per-customer GitHub repos, Vercel deploys).
- **VidForge**: a credit-based AI video generation app with an async job pipeline for multi-minute renders (Next.js, Supabase, fal.ai, Stripe).
- **InstaVenue**: an AI chat widget for event venues, with a site scraper that turns a venue's URL into a configured bot and a live demo page.
- **Grade Decider**: computes the expected value of sending trading cards for professional grading, with a batch optimizer.
- **VANE**: a Shopify storefront for a consumer product brand.
